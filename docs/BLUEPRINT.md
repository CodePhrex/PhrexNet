# Approved product baseline

20 modules: Command Center; Network Discovery; Device Intelligence; Port Scanner; Network Topology; Firewall Intelligence; Vulnerability Lab; Remote Access Center; Packet Analyzer; Network Monitoring; DNS Intelligence; DHCP Intelligence; Active Directory; Wireless Lab; SNMP Explorer; IP Address Management; Configuration Manager; Asset Management; Reporting Center; Network AI.

## Roadmap
1. Discovery foundation: adapters, scoped targets, ports, inventory.
2. Infrastructure intelligence: topology, SNMP, DNS, DHCP, VLANs, firewalls.
3. Administration: authenticated remote sessions and configuration backups.
4. Security: evidence-based CVE correlation and packet analysis.
5. Operations: monitoring and change detection.
6. AI: local-first evidence-based assistance.
7. Commercial release: packaging, licensing and documentation.

## Architecture
.NET 10 WPF/MVVM, SQLite, native networking, optional Nmap, Npcap/SharpPcap, SSH.NET, SNMP, DPAPI, xUnit. Review third-party redistribution terms before bundling. Distinguish observed and inferred topology.

## Design
Midnight #0B1018, slate #172333, cyan #00C8F0, blue #3478F6, green #22C55E, red #F43F5E. Persistent navigation and local-first data.
