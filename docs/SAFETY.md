# Operational safeguards

Only explicitly authorized networks and devices. Require target scope confirmation, exclusions, bounded concurrency, cancellation and audit logs. Passive mode must not send discovery probes. Standard mode uses conservative rate limits. Advanced assessments require maintenance-window approval. No credential guessing or exploitation. Remote management requires supplied credentials. Keep sensitive inventory local; redact credentials from logs. Distinguish suspected vulnerabilities from verified findings. Test in a lab before production.
